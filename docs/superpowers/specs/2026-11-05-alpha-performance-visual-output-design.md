# Alpha Performance 可视化输出设计

状态：已按用户 2026-11-05 的纠正实施输出层样例。

## 目的

每次用户要求查看**某一个** Alpha 的 performance 时，在该次运行的最终输出目录生成一份便于浏览的静态图表报告。原始 CSV、JSON、Alphalens 与 vectorbt 明细继续保留，作为图表的数值来源。不对 135 因子全库预生成报告，不改变因子选择、Gate、回测参数、持仓或冻结库。

## 展示选择

采用用户示例中的多面板研究报告风格，输出 `performance_report.png` 和简短 `performance_report.md`。一张图同时说明因子分组、IC 和实际组合净值；不另建交互平台。直接引用原生 Alphalens tear sheet 无法保证版式，Excel 图表不如单页图片方便浏览。

## 输出合同

报告顶部写入因子 ID、公式、数据截止日、股票池、信号与执行时间、是否为独立 OOS。只画该次运行已经计算或可由其原始明细确定性推导的指标：

1. **G1–G10 分组累计净值**：每个周度信号日按因子值分组，G10 为高分组；从 `t+1 open` 起计算分组收益，逐期链接成展示曲线。图上必须明确是否含成本、重叠持有期以及缺失周的处理。若只有分组均值而没有逐期收益，显示“缺少时间序列”，不得由均值伪造曲线。
2. **IC / RankIC**：使用同一次回测已经计算的前瞻标签，画逐期值及滚动均值；若只计算 5D，图中只画 5D。新增 1D 或 21D 必须是独立标注的诊断计算，不能改变 V5.1 主标签或筛选 Gate。
3. **组合累计净值与成本**：复用同一次 vectorbt 模拟净值、SPY 和股票池等权基准。只有确实重跑 0/10/20 bp 成本场景，才画三条成本曲线；单次 10 bp 运行不得冒充三种成本结果。表格列 CAGR、Sharpe、最大回撤、换手与成本，以实际可得字段为准。

当回测数据被分成开发期与后段历史回放时，左右两栏的时间标签取实际数据边界、各自归一化到 1，并显式标记后段是否已经暴露。当前 Yahoo 500 股样本属于当前快照倒推，2019–2026 全段均为 `DEVELOPMENT_EXPOSED`，不能标为独立 OOS。

## 实施边界

- 新建轻量绘图函数，输入为**单次运行目录中的已核对数据**，输出同目录的 PNG/MD；输入缺失时生成明确的 `PARTIAL` 状态，不制造曲线。
- 在现有单因子运行末尾调用该函数；以后其他单因子 performance 入口也调用同一函数。图表生成失败不能把回测计算结果改为成功或把失败隐去。
- 图表与数值文件共享同一因子 ID、时间窗口、成本和数据源证据。将图表及报告加入 manifest；生成后逐一核对图表所引用的末值与 CSV/JSON。
- 用现有 2020–2026 单因子样例验收版式，确认分组高低方向、成本标签、日期、夏令时、缺失值和无 OOS 声明。

这只改变输出呈现；冻结 V4 的 135 因子可计算公式、V5.1 筛选规则与已暴露历史结果均不变。
